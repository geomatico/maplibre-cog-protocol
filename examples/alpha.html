Orthophoto with an alpha band

An aerial survey delivered as an RGBA COG: the imagery is clipped to the surveyed area and its border is feathered, so it blends into the basemap instead of ending in a hard rectangle.

Transparency comes from the file's own alpha band. No API call is involved, the layer is added like any other. Hover to read the pixel values: outside the surveyed area there is nothing to read.
